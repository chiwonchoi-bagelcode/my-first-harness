# 경로 분리

- 작업 폴더: 시작 시 `process.cwd()`.
- 사용자 전역: `~/.my-first-harness/`.
- 프로젝트 설정 기준: `<작업 폴더>/.my-first-harness/`.
- 스킬은 전역과 프로젝트의 `skills/<이름>/SKILL.md`에서 로드한다. 같은 이름이면 프로젝트 우선이며, 스킬 폴더가 없어도 실행된다.
- 세션은 `~/.my-first-harness/projects/<폴더명-절대경로해시>/<session-id>.json`에 저장한다. `/resume`은 현재 작업 폴더의 세션을 찾는다.
- 기존 프로젝트 내부 `sessions/`에 대한 호환 처리는 없다.
- `.env`는 여전히 현재 작업 폴더에서 읽는다.
- 임시 폴더에서 세션 저장·재개, 프로젝트 구분, 스킬 우선순위 및 폴더 부재를 검증했다. Bun 컴파일 후 빈 작업 폴더에서 시작과 `/quit`을 확인했다. 실제 API 호출은 하지 않았다.

## 기록 원칙

사용자의 명시적 요청 없이 README를 수정하지 않는다. 개발 기록은 `docs/codex-dev-log/`에 작성한다. 개발 과정의 하위 호환은 별도로 요청받지 않는 한 추가하지 않는다.
