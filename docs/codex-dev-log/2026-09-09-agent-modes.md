# plan/edit 모드 연결

- 기본 작업 경로 main에서 구현. README와 세션 파일 형식은 변경하지 않았다.
- agent-mode.ts에 모드 지침과 정책 조합 함수를 분리했다.
- Agent가 런타임 모드를 소유한다. 기본 edit이며 새 세션·resume에서도 현재 모드를 유지한다. 앱을 다시 시작하면 edit이다. 모드 저장은 이번 범위에서 제외했다.
- plan은 writeTextFile/editTextFile을 deny한다. 기본 앱 정책의 셸·MCP ask는 두 모드 모두 유지한다. 이것은 샌드박스나 완전한 읽기 전용 보장이 아니다.
- 요청 조립 때 현재 모드 지침만 system 끝에 붙인다. messages에는 누적하거나 요약하지 않는다.
- CLI/TUI의 /mode plan 및 /mode edit가 동일한 Agent API를 호출한다.
- TUI Shift+Tab은 같은 명령 경로로 전환하고 기록한다. 입력 초안을 유지하며 명령 자동완성으로 처리하지 않는다. 상단 세션 ID 옆에 모드를 표시한다.
- 실행·승인 대기 중에는 전환하지 않는다. TUI 선택 목록이 열려 있으면 먼저 닫아야 한다. 이미 실행 중인 백그라운드 작업은 모드 변경으로 종료하지 않는다.
- 모의 모델로 지침 교체·실제 툴 실행 차단/재허용을 검증하고 Ink 입력 테스트로 Shift+Tab·표시·초안 유지·승인 대기 중 전환 방지를 확인했다. 외부 모델 API와 실제 iTerm2 수동 테스트는 하지 않았다.
