- README·커밋·병합·전역 설치는 변경하지 않는다.

## 구현

- TUI 진입 시 SGR 마우스 보고(1000/1006)를 켜고 종료 시 끈다. 대화 영역의 휠/트랙패드 보고만 3줄씩 스크롤한다. 마우스 보고는 입력창에 삽입하지 않는다.
- 스크롤은 아래에서의 거리 대신 보고 있는 첫 줄을 저장한다. 최신 위치에서는 새 출력을 따라가고, 이전 내용을 보는 중에는 새 항목이 와도 위치를 유지한다. PageUp/PageDown도 유지한다.
- 코어 `tool-end` 이벤트에 결과·성공 여부·소요시간을 전달한다. TUI에서는 첫 번째 비어 있지 않은 줄만 한 화면 줄로 표시한다. JSONL과 모델용 결과는 줄이지 않는다.
- `agent.interrupt()`는 현재 턴의 AbortController를 중단하고 요청 접수 이벤트를 보낸다. TUI는 Esc로 요청하며 완료 전까지 busy를 유지한다.
- 신호는 일반 모델 호출·압축·중첩 LLM 호출의 HTTP fetch, MCP SDK 호출, foreground 셸 실행과 readJob 대기에 전달한다.
- foreground 셸은 기존 JobManager의 프로세스 그룹 종료를 기다린다. 백그라운드 작업 자체는 유지하며 readJob은 대기만 취소한다. 이미 시작된 비취소형 도구는 완료를 기다리고 결과를 보존한다.
- 중단 시 결과가 없는 툴 호출에는 미실행/중단 결과를 채운다. 중단 상태와 스냅샷을 저장한 뒤 `turn-interrupted`를 알리며 같은 세션에서 다음 턴을 실행할 수 있다.
- quit도 실행 중인 턴의 정리를 기다린 뒤 연결·작업 관리자를 dispose한다.

## 한계와 검증 범위

- Esc는 이미 수행한 변경을 롤백하지 않는다. MCP 취소 신호 전송은 원격 서버의 실제 종료 확인과 다르므로 결과에도 미확인 가능성을 남긴다.
- 터미널의 SGR 마우스 지원이 필요하다. 사용자의 실제 터미널/물리 트랙패드 조작은 별도 확인이 필요하다. Ink 입력 보고·화면 이동·입력 오염 방지·모드 복원은 테스트한다.
- 로컬 HTTP 서버의 응답 본문 대기 취소, 실제 셸 PID 종료, 다중 툴의 미실행 결과 채움, 비취소형 도구의 완료 보존, 같은 세션 재사용을 검증한다. 외부 유료 모델 호출은 사용하지 않는다. MCP 신호 옵션 전달 검증은 모의 클라이언트다.
- 전체 테스트는 중간 실행에서 198/198 통과했지만, 최종 199개 검사에서는 198 통과·1 실패다. 기존 이미지 오류 거절 테스트가 unhandled rejection으로 간헐적으로 실패한다. 관련 `loadImage`/이미지 구현은 이번 범위 밖이라 변경하지 않았다. 이번 TUI·중단 테스트는 통과했다.
- 최종 `pnpm build`, `pnpm exec tsc --noEmit`, `git diff --check` 통과.
