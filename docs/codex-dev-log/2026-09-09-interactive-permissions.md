# 앱 기본 승인 정책 적용

- 앱 진입점에서 INTERACTIVE_PERMISSIONS를 에이전트에 전달한다.
- runCommand는 foreground/background 모두 매 호출 승인 요청한다.
- MCP 도구는 이름 접두사를 신뢰하지 않고 ToolManager에 등록된 mcp: 소유권으로 판단한다. 실행 중 새로 등록된 MCP에도 적용한다. 읽기 전용이라는 설명만으로 자동 허용하지 않는다.
- 나머지 내장 툴은 기존처럼 허용한다. 파일 편집·삭제 효과의 차단, 작업 경로 제한, 계획 모드, OS 샌드박스는 아직 구현하지 않았다. ToolSearch는 실제 MCP 실행이 아니므로 자동 허용한다.
- 승인은 한 번만 유효하며 등록/연결 자체의 승인은 이번 범위가 아니다. 라이브러리의 정책 생략 기본값 ALLOW_ALL은 유지한다.
- 모의 테스트로 기본 정책 분류와 동적 등록 MCP의 승인·거부 경로를 검사한다. 실제 외부 API 호출은 하지 않는다.
